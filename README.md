# Resonate Project

This project contains scripts for analyzing and visualizing reasoning failures in audio models.

## Setup

1.  **Create Conda Environment:**

    ```bash
    conda env create -f environment.yml
    ```

2.  **Activate Environment:**

    ```bash
    conda activate resonate_env
    ```

## Usage

To run the visualization script:

```bash
python src/plot_reasoning_failure.py
```
